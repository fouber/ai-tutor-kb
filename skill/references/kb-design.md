# 知识点设计细则

库的质量 = 出题的质量上限。这份细则解决「知识点该怎么划、definition 该写什么、库名和出题侧重点怎么写」。

## 每条知识点两个字段，缺一不可

- `term`：知识点名称，简洁明确，描述核心概念或关键规则。出题时按它定位考点，不能空泛或有歧义。
- `definition`：释义讲解——考查范围、关键规则 / 步骤 / 公式、典型易错点、与相近概念的边界；必要时给简短例题或反例。

两者都会作为提示词交给出题 AI。

## 划分：相近的合并，空泛的写实

判断标准：这条知识点能不能让出题 AI 出一批考点明确、不互相重复的题。

- ❌ 太空泛：`100以内的加减法`——没说考什么，出题只能泛泛而谈。
- ❌ 拆得太碎：`23-8 的计算`、`52-38 的计算`……——这是题，不是知识点，会导致反复出同一类题。
- ✅ 合适：`两位数减法中的退位判断`，在 definition 里写清考查范围和易错点。

**相似的知识点合并成一条**，在 definition 里分别说清各自的考查范围和练习要求，而不是拆成多条近乎重复的点——后者会让出题重复、偏离要求。

**素材可以打包**：一组同类条目（如一个单元的单词表、一组古诗的名句）放进同一条知识点的 definition 里，远好于逐词逐句建点。1500 个单词大约 130 条知识点就能装下。

**规模由实际范围决定**：够练到点上即可，不为显得完整而凑数、堆砌或拆碎。参考已有库时只看目录，不照搬其规模。

## definition：写给出题 AI 看，不是写给孩子看

除了「是什么」，更值钱的是「考什么、哪里会错」：

```
term: 两位数减法中的退位判断
definition: 个位不够减时需要向十位借 1（退位），个位按「加 10 再减」计算，十位记得减去借走的 1。
考查范围：两位数减两位数 / 一位数的竖式与口算，含需要退位与不需要退位两种情况。
易错点：① 忘记十位减 1（如 52-38 算成 24）；② 个位够减却误退位；
③ 连续退位时（如 100-56）十位为 0 需继续向百位借。
```

支持 Markdown 与 LaTeX 公式（`$...$`）。

## 章节铺法

章节是知识点的分组容器，按主题或难度浏览。专项库常见的铺法是由易到难：

1. 前置热身（确认地基）
2. 核心能力，按认知步骤拆开（一章一个步骤）
3. 混合与应用（把步骤组合进真实情境）

同步库可以贴教材目录，但每章内部的知识点仍按上面的标准重写，不要照抄课本标题。

## 库名：简短一句

库名一眼看出练什么即可：`两位数退位减法`、`初二物理 力学`、`六上英语词汇`。不要堆砌「专项 / 冲刺 / 精讲」之类定位词，学科与年级有单独字段，定位与要求写进出题侧重点。

## 出题侧重点（description）：这个库的长期出题约定

description 会随每次出题原样传给出题 AI，是整个库层面的出题要求。写清：

- 侧重考查什么能力（计算 / 概念辨析 / 应用 / 读写…）；
- 难度定位；
- 要重点覆盖的易错方向；
- 表述或语言习惯（如英语库题干用英文）。

2~4 句陈述句即可。**不要在这里指定题型**（题型走 `defaultQType` 字段），也不要复述章节目录。

```
孩子口算熟练，重点考察需要退位判断的竖式计算与两步应用题，避免纯口算题。
混入不需要退位的题目，考察判断而不是机械退位。应用题贴近购物找零、比多少等生活情境。
```

## 默认题型（defaultQType）

不填 = 单选。家长明确说了要练哪种形态才设：

| 家长的说法 | 填 |
|---|---|
| 练听力 | 听力（仅英语 / 小语种库） |
| 背诵默写、背古诗 | 默写（仅语文库） |
| 要能说清过程、讲道理 | 问答 |
| 多选 / 判断 / 填空 | 同名题型 |

与学科不符的题型会被忽略并按单选建库，结果里会提示。用户在 App 练习时仍可临时改题型，这里设的是这个库的常态。
