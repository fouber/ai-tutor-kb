# 懒人学霸 MCP 接入

远程 MCP 服务（Streamable HTTP，无状态），让你的 AI 助手直接读孩子的学情、创建/修改知识库。出题、打印、批阅、复习调度在懒人学霸应用内完成，不经此接口。

- 端点：`https://app.lanrenxueba.com/api/mcp`
- 认证：`Authorization: Bearer lrxb_...`（个人 API 令牌）

## 获取令牌

登录懒人学霸 → **我的 → AI 连接器** → 创建令牌。明文只显示一次，丢了就删除重建。令牌只能访问下面六个工具，碰不到支付与账号设置；可随时在同一页面删除，相关连接立即失效。

⚠️ 令牌只写进客户端配置，**不要粘贴到对话里**。

## 各客户端配置

**Claude Code**（创建令牌时弹窗里会给出含真实令牌的完整命令）

```bash
claude mcp add --transport http lanrenxueba https://app.lanrenxueba.com/api/mcp \
  --header "Authorization: Bearer lrxb_你的令牌"
```

**claude.ai（网页/桌面）**：设置 → 连接器 → 添加自定义连接器，填端点 URL 与上述 Authorization 头。

**Cursor**（`~/.cursor/mcp.json`）：

```json
{
  "mcpServers": {
    "lanrenxueba": {
      "url": "https://app.lanrenxueba.com/api/mcp",
      "headers": { "Authorization": "Bearer lrxb_你的令牌" }
    }
  }
}
```

配合本仓库的 [skill](../skill/SKILL.md) 使用效果最佳：MCP 负责连接，skill 负责教会助手怎么用好。服务端 `initialize` 也会下发一份 instructions，与 skill 的建库规则同源。

## 工具一览

| 工具 | 作用 |
|---|---|
| `get_study_report` | 学习报告：连续打卡、各库熟练度与待复习量、薄弱知识点 TOP、近 14 天练习量、题数余额；传 `kbId` 聚焦单库时另给按章熟练度全景 |
| `get_wrong_book` | 读某个库的错题本（只读，最近答错在前；`limit` 默认 20、最大 50）：题面、选项与答案、学生作答（有记录时；纸面练习可能只回传对错）、知识点熟练度与重练熟练度。用于分析错因、规划专项库；变式重练本身在应用内的错题本进行 |
| `list_kbs` | 列出我创建的与在学的知识库：id、学科年级、规模、是否在学 |
| `get_kb` | 看某个库的目录结构（章节带序号 + 知识点名称）；传 `chapterId` 读整章知识点全文 |
| `create_kb` | 创建知识库（一次提交完整章节与知识点），落为**私有**库，返回库链接；中途失败自动清理半成品，整包重试即可 |
| `update_kb` | 修改自己创建的库，按操作列表顺序执行，见下表 |

知识库数据结构（`create_kb` 的入参形状）见 [schema/kb.schema.json](schema/kb.schema.json)。

### `create_kb` 字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `title` | ✓ | 库名：简短一句，一眼看出练什么，如「两位数乘法」「初二物理 力学」；不要堆砌「专项 / 冲刺」之类定位词 |
| `subject` | ✓ | 学科，标准中文，见[学科与年级](#学科与年级) |
| `grade` | ✓ | 年级，标准中文，见[学科与年级](#学科与年级) |
| `description` |  | **出题侧重点**：随每次出题原样传给出题 AI，相当于这个库的长期出题约定——侧重能力、难度定位、易错方向、表述习惯。2~4 句；不写题型、不复述目录 |
| `defaultQType` |  | 默认题型：单选 / 多选 / 判断 / 听力 / 默写 / 填空 / 问答，不填 = 单选。听力仅英语 / 小语种库，默写仅语文库，不符会被忽略并在结果里提示 |
| `chapters` | ✓ | 章节列表，每章 `title` + `points`；每条知识点 `term` + `definition` 缺一不可 |

### `update_kb` 操作

| op | 作用 |
|---|---|
| `set_meta` | 改库名 / 出题侧重点 / 学科 / 年级 / 默认题型（`defaultQType` 填「默认」恢复单选） |
| `add_chapter` | 加一章，可内联 `points` 建章即塞点；同名章节自动复用；可带 `position` 插到指定位次，默认追加末尾 |
| `add_points` | 向 `chapterId` 追加知识点，单次 1–200 条；同章内 `term` 相同的自动跳过 |
| `update_point` / `remove_point` | 改 / 删单条知识点（`pointId` 来自 `get_kb` 传 `chapterId` 的结果） |
| `remove_chapter` | 删一章，连带删除章下全部知识点，慎用 |
| `move_chapter` | 把某章移到 `position` 位次 |
| `reorder_chapters` | 按 `chapterIds` 一次排定全部章节顺序，须包含该库全部章节 |
| `rename_chapter` | 改章名 |

位次 `position` 从 1 数起，与 `get_kb` 输出的章节序号一致，超出范围自动落到末尾。

## 学科与年级

`subject`、`grade` 在工具 schema 里是枚举，传标准中文即可：

- **学科**：语文、数学、英语、物理、化学、生物、历史、地理、科学、编程、音乐、美术、小语种、其他
- **年级**：
  - 大阶段：学前、小学、初中、高中、大学、通用
  - 小学：一年级 ~ 六年级
  - 初中：预备班、初一、初二、初三（五·四制的七 / 八 / 九年级也可直接填，归到初一 ~ 初三）
  - 高中：高一、高二、高三
  - 大学：大一、大二、大三、大四

尽量选能确定的最细一级。传了列表外的写法服务端会尽量归一（如「七年级」→初一、「Python」→编程、「日语」→小语种、「奥数」→数学），实在认不出会记为「其他」/「通用」并在结果里提示，据提示用 `update_kb` 的 `set_meta` 改正即可。

## 批量写入与大库

- **限额**：每库 ≤60 章、≤600 知识点；`add_points` / `add_chapter` 内联单次 ≤200 条；`term`、`definition` 长度不限。超出即报错、不写入。
- **分片**：单次调用建议 ≤100 个知识点（工具参数是模型一次性生成的，过大可能被输出上限截断；建议值，服务端不校验）。更大的库：`create_kb` 先提交前面的章节，剩余用 `update_kb` 的 `add_chapter` 逐章补齐；单章超 200 条再分批 `add_points`。
- **重试安全（幂等）**：同章内 `term` 相同的条目自动跳过、同名章节自动复用——超时或中断后把该章整包重传即可，不会产生重复数据。
- **漏了一章不用重建**：`add_chapter` 带 `position` 直接插到指定位次；顺序不对用 `move_chapter` / `reorder_chapters` 调整。
- **素材打包**：一组同类条目（如一个单元的单词表）放进同一条知识点的 `definition`，远好于逐词建点——1500 个单词约 130 个知识点。
- **整本教材 / 超大规模导入**不适合走本接口：请在懒人学霸 App 内用「AI 建库」（拍照 / 大纲生成）完成。本接口适合对话确认式的中小规模建库。
- 写入响应会回显写入后的章节与知识点名称，无需再调 `get_kb` 核对。

## 设计与安全说明

- **写入只建私有库**：公开、分享由用户在应用内操作；助手提交的库在用户打开链接点「开始学习」之前是惰性的——不出题、不扣费、不进任何人视野，等价于草稿。
- **确认纪律在对话侧**：skill 要求助手在调用写工具前把完整清单列给用户确认；服务端 `initialize` 的 instructions 里同样声明了这条纪律。
- **令牌**：服务端只存 SHA-256 哈希；鉴权中间件仅挂在 `/api/mcp` 一条路由上，权限边界由路由拓扑保证。
- **计费**：本接口所有工具均不消耗题数。出题发生在应用内，按题数计费。
